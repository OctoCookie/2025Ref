## 🧠 Опис функціоналу

-   зчитування _.txt файлів, _.mat файлів;
-   формування ознаки RUL;
-   очищення сенсорів від констант;
-   масштабування даних;
-   побудова моделей:
    RandomForestRegressor
    XGBoostRegressor;
-   калібрування прогнозів:
    лінійна регресія,
    Isotonic Regression;
-   післяобробка:
    MA (Moving Average),
    EMA (Exponential Moving Average);
-   побудова графіків;
-   вивід таблиць:
    RF raw / linear / iso / iso+MA / iso+EMA
    XGB raw / linear / iso
-   обчислення:
    MAE, RMSE, R².
-   фільтрація сигналів (band-pass);
-   розбиття на вікна (sliding windows);
-   формування ознак:
    RMS, variance, kurtosis, skewness, crest factor,
    спектральні показники;
-   вивід:
    PR-кривих;
    reliability diagrams;
    Brier score;
    графіків "Raw vs Filtered signal";

## 🧱 Опис основних класів / файлів

| Клас / Файл                      | Призначення                                                                                                |
| -------------------------------- | ---------------------------------------------------------------------------------------------------------- |
| `pipeline.py`                    | Головний файл, містить програму                                                                            |
| `run_nasa_rul_pipeline()`        | ФФункція для повного циклу обробки NASA датасету: передобробка, моделювання, калібрування, оцінка          |
| `run_vibration_fault_pipeline()` | Функція реалізації повного пайплайна для вібраційних даних: фільтрація, ознаки, класифікація, калібрування |
| `isotonic_calibrate()`           | Побудова моделі ізотонічної регресії для калібрування                                                      |
| `linear_calibrate()`             | Функція лінійної калібровки прогнозу                                                                       |
| `moving_average()`               | Реалізація ковзного середнього (MA) для післяобробки прогнозів                                             |
| `exponential_moving_average()`   | Реалізація EMA для згладжування прогнозних рядів                                                           |
| `extract_time_features()`        | Діставання часових ознак з вібраційних сигналів                                                            |
| `extract_freq_features()`        | Діставання спектральних ознак з вібраційних сигналів                                                       |
| `bandpass()`                     | Реалізація смугового фільтра для сигналів                                                                  |
| `reg_metrics()`                  | Обчислення MAE, RMSE, R² для регресійних моделей                                                           |
| `prob_metrics()`                 | Обчислення ROC-AUC та Brier score для класифікації                                                         |
